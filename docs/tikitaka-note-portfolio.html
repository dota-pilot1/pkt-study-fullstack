프로토타입 소개

목표와 완료 기준을 가진 할 일을 만들고, 선택한 API·작업 경로·세부 계획을 Agent에게 구현 지시로 전달합니다. 구현 후에는 코드 리뷰와 테스트 근거를 남기며, 검증된 설계와 해결 경험을 계층형 노트로 정리합니다.

학습과 개발의 연결 기본기, 언어, 프레임워크, 메이저 스펙과 실제 기능 개발을 하나의 루프로 운영합니다.
기술 부채까지 관리 리뷰에서 확인한 개선점과 선택의 이유를 다음 작업의 기준으로 재사용합니다.

기술 구성

Tauri 데스크톱 패키징 위에 Next.js Full-stack과 SQLite를 결합해 화면·기능·학습 데이터를 하나의 앱으로 다룹니다. 로컬에서 빠르게 시작하고, 배포와 공유도 간단하게 가져갈 수 있습니다.
